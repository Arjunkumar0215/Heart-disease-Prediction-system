🚀 From Raw Data to Real-World Impact! 🫀Excited to share my latest project completed during my internship at Jharkhand Government Tool Room, Ranchi!I developed an End-to-End Heart Disease Prediction System using Machine Learning to predict heart disease risk from patient health parameters.

🔍 What I built:

 This wasn't just model training. I handled the complete ML lifecycle:

✅ Data Cleaning & EDA

✅ Data Visualization & Storytelling

✅ Feature Engineering, Feature Selection & VIF Analysis

✅ Handling Missing Values, Outliers, Skewness & Kurtosis

✅ Model Building: Logistic Regression vs Decision Tree vs SVM

✅ Evaluation: Accuracy, Precision, Recall, F1-Score, Confusion Matrix

✅ Feature Importance & Overfitting Analysis💻 And made it LIVE!

Deployed an interactive Streamlit Web App where anyone can enter health parameters and get real-time predictions. Because a model is useless until users can use it!This project taught me how to take messy healthcare data and turn it into a user-friendly product.

🛠️ Tech Stack: Python | Pandas | NumPy | Matplotlib | Seaborn | Scikit-learn | StreamlitBig thanks to Jharkhand Government Tool Room, Ranchi for this amazing learning opportunity
